Section 3.3. Scoping the Decomposition: Not Every Element Deserves Equal Attention.

A real system can easily contain dozens of nominally distinct elements, and analyzing all of them with equal depth wastes effort on the ones that don't matter while diluting attention on the ones that do. A documented industry example makes the filtering step concrete: an automotive transmission analysis started with 28 system elements and, using pre-calculations, experience from similar transmissions, and an ABC-style criticality classification, reduced the reliability-relevant scope to 12 elements, the power-transmitting parts (input or output shafts, gears, fitting-key connections, bearings) and the radial seal rings. The other 16 elements weren't ignored entirely; they were consciously screened out of the detailed reliability analysis because engineering judgment and prior experience indicated they weren't going to be life-limiting.

Interactive figure. Twenty-eight dots, one per transmission element. Twelve are highlighted as reliability-relevant; sixteen are screened out of the detailed analysis.

This matters for two reasons. First, it's the honest answer to how detailed should my decomposition be, detailed enough to capture every element that plausibly limits system life, and no more, because unlimited detail is not actually free; it's a tax on every downstream D F M E A and duty-cycle exercise. Second, the same source example shows the natural next step once scoping is done: starting from a function block diagram (or a power-flow schematic) of the surviving elements, the reliability block diagram can be built directly, because the function diagram already shows how each element is stressed and how its failure propagates to the rest of the system.

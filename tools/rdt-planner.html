Trading units for test time (requires a lifetime model)

The binomial plan says nothing about running fewer units longer. That exchange is only valid under an assumed life distribution. With a Weibull shape β and no failures, running each unit for ttest instead of the mission tm changes the required count by (ttest/tm)−β. The result is only as trustworthy as β, and it assumes the extended test exercises the same failure mechanisms.

Required units vs. test length for several β

Steep β (wear-out) buys a lot of sample reduction from extra test time; β near 1 buys little. If β is uncertain, the honest plan uses the lowest plausible β, which is the highest curve.

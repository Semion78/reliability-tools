# Reliability Engineering Tools

Free interactive reliability engineering tools by Semion Gengrinovich. Each tool is a single HTML file that runs in the browser with preloaded worked examples; no data is uploaded.

| Tool | File |
|---|---|
| RDT Planner | tools/rdt-planner.html |
| Fixed-Duration Test Planner | tools/fixed-duration-test-planner.html |
| OC Curve: Accept / Reject Batch | tools/oc-curve.html |
| ALT & Miner's Rule Workbench | tools/alt-miners-rule.html |
| Stress–Strength Interference Console | tools/stress-strength-monte-carlo.html |
| Mann-Kendall Trend Test | tools/mann-kendall.html |
| DOE & Gage R&R Workbench | tools/doe-grr-workbench.html |
| Taguchi Robust Design | tools/taguchi-robust-design.html |
| Fault Tree Lab | tools/fault-tree-lab.html |

Published with GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
